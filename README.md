## Présentation

Version React Native de Burba destinée à la production d'un APK Android : configuration native, icônes et écran de démarrage.

**Pourquoi ce choix.** Séparer la branche de build de la branche de développement évite de polluer le dépôt applicatif avec la configuration native.

---

## Ce que fait le projet

- Configuration native Android
- Stockage local `AsyncStorage`
- Chaîne de build APK
